📧 Gmail — Importación automática de ofertas

Configuración adicional en Google Cloud Console (1 vez):
1. APIs & Services → Library → Busca Gmail API → Enable
2. OAuth consent screen → Add scope: gmail.readonly
3. Authorized JS origins: https://fjmacarmen-blip.github.io
4. ⚠️ Google mostrará "App no verificada" — pulsa "Continuar" para seguir
5. En Búsqueda Diaria → botón 📧 Gmail para sincronizar
